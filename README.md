\# YojnaMitra — AI-Powered Government Scheme Assistant



YojnaMitra helps Indian citizens discover government welfare schemes relevant to their profiles.



\## Technology Stack



\* Next.js

\* React

\* TypeScript

\* Tailwind CSS

\* Python

\* Supabase PostgreSQL

\* Supabase Auth

\* pgvector for semantic search



\## Project Structure



\* `web/` — Next.js web application

\* `data\_pipeline/` — Python data collection and processing

\* `database/migrations/` — SQL database migrations

\* `database/seed/` — Initial and test data

\* `docs/` — Project documentation



\## Main Features



\* Government scheme discovery

\* Profile-based eligibility matching

\* Scheme search and filters

\* Hindi and English support

\* AI assistant using Retrieval-Augmented Generation (RAG)

\* Official source links and verification dates



\## Important Note



Eligibility results provide informational guidance and are not official government eligibility decisions.
